# dae - Landing Page для ухода за волосами

Адаптивная верстка лендинга для бренда по уходу за волосами "dae". Проект создан на основе макета из Figma.

## 📋 Описание проекта

Одностраничный сайт (лендинг), который включает в себя:

- Верхнюю панель с объявлением и шапку сайта.
- Главный баннер (Hero Section) с фоновым изображением и кнопкой призыва к действию.
- Раздел с описанием продукта (Увлажняющая маска Monsoon).
- Сетка товаров (Выбери красивую баночку).
- Полноэкранный баннер с призывом (Почувствуй тепло...).
- Раздел «О нас» (Знакомьтесь, Дэ) с эффектом наложения текста на изображение.
- Галерея из социальных сетей (Подписывайтесь на нас @Daehair).
- Подвал сайта (Футер) со ссылками и контактами.

## 🚀 Технологии

- **HTML5** — семантическая разметка.
- **CSS3** — стилизация, в том числе:
  - Flexbox (для выравнивания элементов шапки, футера и секций).
  - CSS Grid (для сетки товаров и галереи Instagram).
  - Медиазапросы (для адаптивности под планшеты и мобильные устройства).
  - Переменные CSS (пользовательские свойства для цветов и шрифтов).
